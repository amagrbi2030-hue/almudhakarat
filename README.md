# المذاكرات الإيمانية

تطبيق «المذاكرات الإيمانية في جهد الدعوة إلى الله»، ويضم قسمين: جهد الرجال وجهد النساء.

## المميزات
- يعمل بالكامل بدون إنترنت، والخطوط كلها مدمجة داخل `index.html`.
- 15 ثيماً، وألوان البطاقات تتغير مع الثيم المختار.
- 7 أنواع خطوط و3 أحجام.
- 6 أنواع لزخرفة الخلفية.
- بحث في جميع النصوص.
- يمكن تثبيته على الجوال كتطبيق (PWA) عند نشره على GitHub Pages.

## محتوى المستودع
| الملف | الوظيفة |
|---|---|
| `index.html` | التطبيق كاملاً (النصوص، التصميم، الخطوط) |
| `manifest.webmanifest` | اسم التطبيق وأيقوناته عند التثبيت |
| `sw.js` | يحفظ التطبيق على الجهاز ليعمل بدون إنترنت |
| `icons/` | أيقونات التطبيق |
| `fonts-licenses/` | تراخيص الخطوط المدمجة (SIL Open Font License) |

## النشر على GitHub Pages
1. ارفع ملفات هذا المجلد إلى جذر المستودع.
2. افتح **Settings ← Pages**.
3. في **Source** اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، واضغط **Save**.
4. بعد دقيقة أو اثنتين يصبح التطبيق متاحاً على: `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`

## الخطوط
الخطوط المدمجة كلها مجانية بترخيص SIL Open Font License:
Amiri، Tajawal، IBM Plex Sans Arabic، Noto Sans Arabic، Carlito، Vazirmatn، Noto Naskh Arabic، Cairo.

خطوط Calibri وAdobe Arabic وDIN Next LT Arabic تجارية، فلم تُدمج. إذا كانت مثبتة على الجهاز تُستخدم مباشرة، وإلا تظهر بالبدائل التالية:

| الخط | البديل المدمج |
|---|---|
| Calibri | Carlito للحروف اللاتينية، وVazirmatn للعربية |
| Adobe Arabic | Noto Naskh Arabic |
| DIN Next LT Arabic | Cairo |
